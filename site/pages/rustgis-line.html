Линейка для RustGIS

Пять наших расширений для RustGIS. Инструменты считают так же, как наши модули QGIS, и сверены с ними на тех же примерах. У каждого расширения своя вкладка на ленте RustGIS, ставится оно из файла кнопкой Install From File. Нужен RustGIS 0.7.0 и новее.

Isoliner3D для RustGIS

0.6.0

3D-сцена прямо из слоёв карты и десять инструментов горной геологии - тела выработок, оболочки рудных тел, стволы скважин, отчёт по уступам, 3D-плотность.

Выпуск Страница

Isoliner для RustGIS

0.1.2

Тринадцать инструментов кригинга, разрезов и фракталов - вариограмма, кросс-валидация, декластеризация, содержания по пласту, фрактальная размерность.

Выпуск Страница

Topoliner для RustGIS

0.1.0

Одиннадцать инструментов топологии покрытий - проверка и очистка полигонов и линий, сшивка узлов, ввод контуров, упрощение.

Выпуск Страница

Routeliner для RustGIS

0.1.1

Восемь инструментов линейной привязки - сборка и калибровка маршрутов, события по пикетам, продольный профиль.

Выпуск Модуль QGIS

RustPlanetX

0.6.1

3D-глобус PlanetX рядом с картой RustGIS - рельеф, снимки и слои проекта на глобусе. Windows, Linux и macOS.

Выпуск Страница

rustgis-kit

Общая основа расширений Isoliner3D, Isoliner, Topoliner и Routeliner - связь с RustGIS, окна инструментов, системы координат, сборка пакета. Открытый крейт под Apache 2.0.
