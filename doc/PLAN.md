# План Isoliner Scene

Этапы и признаки их готовности. Состав этапов и приёмку решает автор.

## Этап 1. Открыть пакет и показать его камерой пакета

Сделано 12 ноября 2026 года, проверено без окна в облаке (Linux,
программная отрисовка lavapipe).

- Чтение и запись `.i3dscene`, сверка с пакетом демо модуля.
- Камера окна Isoliner3D: матрицы как у pyqtgraph, мышь, вписывание.
- Отрисовка: тела с цветом вершин, линии, прозрачные тела от дальних
  к ближним, сглаживание краёв, преувеличение в шейдере.
- Окно: открыть, перетащить файл в окно, сохранить как, части
  со скрытием, виды облёта, оборот, преувеличение, непрозрачность,
  русский и английский.

Признак готовности на машине автора:

1. `cargo test --workspace` зелёный на Windows.
2. `cargo run -p isoliner-scene --release -- fixtures/scene_demo.i3dscene`
   показывает штрек, сбойку, ствол, кровлю пласта и короб.
3. Пакет, выгруженный из окна Isoliner3D (кнопка выгрузки, формат
   «Пакет сцены Isoliner3D»), открывается и выглядит как в QGIS
   с той же камерой. Сверка - два снимка рядом, модуль и программа.

Принят автором 12 ноября 2026 года на Windows 10 (Rust 1.99.1,
QGIS 4.0.3, Isoliner3D 1.4.13).

- Пункты 1 и 2 выполнены. `cargo clippy --workspace --all-targets
  -- -D warnings` тоже без замечаний.
- Пункт 3 сверен на пакете из окна Isoliner3D со слоями
  «2.09 Демонстрационная выработка». Зарисовки бортов, цвет, камера
  и вид облёта совпадают. Короб модуль кладёт в пакет всегда, в окне
  он виден только при `state.axes_on`. Программа теперь скрывает
  оформление так же (`SceneMeta::part_shown`).
- Расхождения, оставленные на потом:
  - точки (пробы, борозды) модуль в пакет не выгружает, правка
    в модуле (`_export`);
  - фон окна модуля - градиент (`state.bg_grad`), в программе фон
    ровный.

## Этап 2. Видео

- Запись облёта и оборота в MP4 тех же кадров, что пишет модуль
  (`video.py`, Media Foundation в Windows).
- Открытое решение автора: через что писать MP4. Media Foundation
  из Rust требует `unsafe`, его правила запрещают. Варианты - кадры PNG
  и внешний ffmpeg, крейт кодировщика на чистом Rust, исключение для
  одного файла по решению автора.

## Этап 3. Обрезка и разрез

- Перенос обрезки коридором и разреза по линии из окна модуля
  (`slice3d.py`, `section3d.py`, шкалы разреза `axes.section_scales`).
- Образцы - новые файлы в `fixtures/` из модуля.

## Этап 4. RustGIS

- Крейты сцены подключаются к `C:\Dev\planetx-lite` зависимостью
  по git или по пути. Окно сцены - вид в `planetx-rustgis`, части
  собираются из слоёв RustGIS.
- Окно инструмента в RustGIS строится по `tools.json` (`tool-spec`),
  расчёт - из крейта `tools`. Первые инструменты - 2.23 и 2.24.

## Этап 5. Остальные инструменты

Инструменты переходят в объекты в модуле по одному
(`ARCHITECTURE.md` модуля, «Перенос остальных инструментов»).
За каждым следует перенос сюда: образцы прогонов в `tool_runs.json`,
расчёт в `crates/tools`, сверка.
