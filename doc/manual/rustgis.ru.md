# Isoliner3D в RustGIS

Isoliner3D для RustGIS - расширение RustGIS с той же сценой и теми же
инструментами, что у модуля QGIS. Расширение работает в RustGIS
для Windows начиная с версии 0.5.

## Установка

1. Скачать пакет `isoliner3d-0.4.0.rgplugin` со страницы выпуска.
2. В RustGIS открыть вкладку «Модули» и нажать «Установить из файла».
3. Выбрать пакет и подтвердить установку.

RustGIS предупреждает, что расширение - программа на компьютере, а не
модуль в песочнице. Так устроены все расширения-программы RustGIS.

После установки на вкладке «Модули» появляется группа Isoliner3D. В ней
кнопки «Сцена Isoliner3D», «О программе Isoliner3D» и кнопки
инструментов. Те же инструменты лежат в панели «Инструменты» RustGIS,
в группе Isoliner3D.

Установка из командной строки.

```
rustgis-cli plugins install isoliner3d-0.4.0.rgplugin
```

Удаление - «Менеджер модулей», строка Isoliner3D.

## Сцена

Кнопка «Сцена Isoliner3D» открывает окно сцены. В сцену идут видимые
векторные слои карты. Окно то же, что у программы Isoliner Scene
и у окна просмотра модуля QGIS - плашка значков, «Параметры сцены»,
виды облёта, видео и выгрузка. Работа с окном описана в главе «Окно
просмотра».

Слои изменились - повторное нажатие «Сцена Isoliner3D» собирает сцену
заново. Открытое окно перечитывает её само, второе окно
не открывается.

Пакет сцены `.i3dscene`, записанный модулем QGIS, открывается кнопкой
«Открыть…» в окне сцены.

## Инструменты

В RustGIS сейчас два инструмента.

- 2.24 Тело вдоль выработки.
- 2.17 Стволы скважин по инклинометрии.

Поля, подсказки и сообщения у них те же, что у модуля QGIS. Страницы
инструментов в главе «Инструменты» общие для QGIS и RustGIS.

Итог ложится в проект новым слоем. Отмена в RustGIS (Ctrl+Z) убирает
его.

## Чем RustGIS отличается от QGIS

- Слой RustGIS помнит свою систему координат, но расширению отдаёт
  объекты в градусах WGS 84 и без высоты Z. Для расчёта градусы
  переводятся в метры зоны UTM по середине входных слоёв. Итог
  переводится обратно в градусы. Номер зоны печатается в сообщениях
  расчёта.
- Система сцены - как у карты. По умолчанию сцена строится в проекции
  карты RustGIS, если у карты код EPSG в метрах. Карта «Меркатор»,
  глобус или система в градусах дают сцену в метрах зоны UTM. Код
  в поле «Система координат сцены (EPSG)» окна «Параметры сцены»,
  вкладка «Вид», важнее карты. Новая система применяется при следующем
  нажатии «Сцена Isoliner3D». Слои в систему сцены переводит RustGIS.
- Высоты берутся из полей. У 2.24 это поле отметки оси или постоянная
  отметка. У 2.17 это поле отметки устья.
- Тело 2.24 ложится в проект контуром в плане - верхними гранями тела.
  У контура поля длины, площади сечения и объёма. В сцене этот слой
  показывается телом с высотой.
- Устья 2.17 - точечный слой или таблица с X и Y в метрах. Точки
  считаются через зону UTM. У таблицы без точек X и Y берутся из полей,
  а в поле «Система координат X и Y (EPSG)» указывается их код,
  например EPSG:28410. Стволы тогда ложатся в проект в этой системе,
  RustGIS ставит их на место сам.
- Инструменты с телами на входе (2.11, 2.12, 2.14, 2.23) и 2.18 со
  стволами с Z остаются в модуле QGIS. Слой RustGIS не держит ни тел,
  ни линий с Z.
- Сцена следит за слоями по нажатию кнопки. Следить без нажатия сможет
  RustGIS с сессиями расширений.

## Проверка без установки

Пакет можно проверить командой одного прогона, RustGIS при этом ничего
не ставит.

```
rustgis-cli run --plugin isoliner3d-0.4.0.rgplugin --data оси.geojson ^
  --cmd "gp.run={\"tool\":\"plugin:isoliner3d/sweep-body\",\"params\":{\"input\":\"оси\",\"elev\":-300}}"
```
