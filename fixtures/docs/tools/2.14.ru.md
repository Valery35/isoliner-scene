## 2.14 Зональная статистика оболочек

Считает по каждому телу, сколько объектов в него попало, и записывает числа в атрибуты тела.

Точки: число внутри и сумма атрибута. Линии: число линий, задевших тело, и длина их частей внутри. Полигоны: число полигонов, у которых хоть одна вершина внутри.

Линия режется телом: отрезок пересекается с поверхностью, точки сортируются вдоль него, и в длину идёт только часть внутри. Отрезок, прошивший тело насквозь между своими вершинами, не пропадает.

Ноль и пусто - разные вещи. Тело, внутри которого ничего нет, получает ноль: это измеренный факт. Незамкнутое тело получает пусто и попадает в предупреждение: у него нет внутренности.

Повторные прогоны по одному слою тел складываются: результат предыдущего подаётся как слой тел следующему, и каждый прогон добавляет свои поля. Столкновение имён - отказ, если не разрешена перезапись.

По атрибуту считается сумма, среднее, минимум, максимум, стандартное отклонение, медиана и квантили, на выбор. У точек и полигонов каждый объект весит одинаково, у линий вес - длина их части внутри тела: интервал опробования, вошедший в тело наполовину, весит половину. Пустые значения атрибута не участвуют.

Сумма по телам сходится: длина линий внутри всех тел плюс длина снаружи равна полной длине, и это печатается в журнал.

Второй результат, необязательный, - сами объекты с телом, в которое они попали: поля zone, zone_ids и zone_n. Так видно, какие пробы дали итог тела.

| Поле | Что задаёт |
|---|---|
| **Тела (полигоны с Z)** | Слой тел: замкнутые оболочки, по одной на объект. У каждого тела появятся свои поля со счётом. Незамкнутое тело получает пусто, а не ноль: у него нет внутренности, и считать там нечего. |
| **Что считать (объекты с Z)** | Что считать: точки, линии или полигоны с высотой. Блочная модель, скважины, следы выработок, разломы. |
| **Имя полей результата (пусто - от слоя)** | Имя для полей результата. Пусто - от имени слоя, приведённого к латинице. К нему добавятся суффиксы: _n число объектов внутри, _len длина линий внутри, _sum, _mean, _std и другие по выбранной статистике. Задавайте своё, когда гоняете инструмент по одному слою тел несколько раз с разными данными. |
| **Атрибут для статистики** | Числовой атрибут для статистики: металл или объём блока, мощность, содержание. Пусто - только счёт. |
| **Статистика по атрибуту** | Что считать по атрибуту. Сумма - запас, когда атрибут уже металл блока. Для содержания нужны среднее, разброс и квантили. У линий среднее и квантили взвешены по длине внутри тела, как при подсчёте по композитам. |
| **Разрешить перезапись полей** | Разрешить перезапись полей с тем же именем. Без этого повторный прогон с тем же именем - отказ: иначе второй результат тихо затёр бы первый. |
| **Тела со статистикой** | Тела со всеми прежними полями и новыми полями счёта. Чтобы накопить несколько прогонов, подавайте результат предыдущего как слой тел следующему. |
| **Поле тела для объектов (пусто - номер)** | Поле тела, которое пишется объектам: имя или код тела. Пусто - номер объекта тела в слое. |
| **Объекты с телом** | Сами объекты с полем тела, в которое они попали: zone - первое тело, zone_ids - все через точку с запятой, zone_n - сколько тел. Объект вне тел получает пусто и ноль. Без этого слоя видно только итог по телу, но не какие пробы его дали. |
